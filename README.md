# 踏格 · StepLattice

踏格是一台参考 DDR 街机布局的 DIY 单人四键脚台，使用 2020 铝型材骨架、四块可拆的 PC 箭头板和独立的低位钢制扶手副架。这一版基于 Claude 的并轨骨架，增加宽孔距扶手脚座。R1 已完成数字装配和几何检查，下一步是单格打样、踩踏冲击和扶手稳定性验证。

R1 壳体为 **890 × 1080 mm**，格距 **280 mm**。每块箭头使用 **274 × 274 × 10 mm** 的等厚 PC，四角各做 **8 × 8 mm** 的平切角。每键通过四个 FSR 判键，钢挡块在名义 **0.5 mm** 行程处接过重踩载荷。扶手握把顶距固定踏面 **920 mm**。

材料和采购尺寸以 [设计说明](DESIGN.md) 与 [零件清单](BOM-octagon.csv) 为准。公开模型是打样稿，实际加工与使用前按样件回填接口公差、检查扶手锚固并完成承载验证。
